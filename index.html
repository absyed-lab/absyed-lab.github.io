Research code

Token-efficient self-improving coding agent

LangGraph, local Ollama models, PostgreSQL. Work in progress.

A coding agent that retries its own solution, and an LLM judge that decides when another attempt is no longer worth the tokens. The question: can a cheap judge stop the loop early while keeping most of the pass rate of a full loop? The open problem is checking whether the judge's stop decisions are right. Results are not published yet.

Agent Memory OS

ChromaDB, Groq or Ollama, Streamlit.

A support agent with four memory layers: short-term, long-term, episodic and reflection. An experiment in what an agent should carry from one session to the next. No systematic evaluation yet.
